Skills System

How OpenClaw selects, loads, and applies specialized skills to handle different types of requests.

Skill Selection Pipeline
💬
Step 1
Message Arrives
User sends a message via any channel — WhatsApp, Telegram, webchat, etc.
🔍
Step 2
Scan Descriptions
Agent reads all <description> entries from available_skills — no file reads yet.
🎯
Step 3
Select Best Match
If one skill clearly applies, it's selected. If multiple match, the most specific wins. If none match, no skill is loaded.
📄
Step 4
Read SKILL.md
Only now the skill file is read — persona, tools, instructions, knowledge are loaded into context.
⚡
Step 5
Execute
Agent follows skill instructions, uses skill-specific tools, adopts persona and tone defined in the skill.
