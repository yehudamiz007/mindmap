Tool Execution Pipeline

Every tool call goes through the same pipeline: the agent requests a tool, the policy engine validates access, the tool executes in a sandboxed context, and the result is returned to the agent's context window. Multiple tool calls can execute in parallel within a single LLM turn. Click the pipeline stages or tool categories above to explore.
