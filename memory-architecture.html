Context Window
Active session • In-memory • Ephemeral
Everything the agent sees right now. The full conversation history, system prompt, tool outputs - all packed into a single sliding window. When it fills up, compaction kicks in automatically.

Prompt Cache
Provider-side • Auto • Cost optimization
Anthropic caches the static parts of your context (system prompt, skill files, memory) server-side. Each new message re-uses the cache instead of re-processing everything. Result: 90%+ cache hit rate and up to 10x cheaper API calls.

Daily Memory Files
Disk • Persistent • Raw logs
Every session writes a daily log file: memory/YYYY-MM-DD.md. Raw events, decisions, conversations. The agent's raw journal - everything that happened, unfiltered.

MEMORY.md
Long-term • Curated • Always loaded
The agent's curated long-term memory. Loaded at the start of every session. Contains family info, key decisions, project state, skills, preferences - everything worth remembering forever. Updated by the agent, for the agent.

Git Repository
Remote • Versioned • Disaster recovery
The entire workspace is a git repo. All dashboards, scripts, memory files - versioned and pushed to GitHub. Survives machine crashes, reinstalls, anything. The ultimate backup layer.
