### Critical Bug Found & Fixed
- **Root cause of blank screen:** `theme` was used at module scope (outside components) in `Home.jsx`, `Profile.jsx`, `UserPage.jsx` - in const arrays like `LEVEL_SYSTEM`, `LIVE_EVENTS`, `POST_TYPES`, `ACTIONS`. Theme comes from React Context so it's undefined at module load time.
- **Fix:** Replace `theme.accent` etc in module-scope constants with hardcoded hex values. Add `const { theme } = useTheme()` only INSIDE component functions.
- **Also:** `TransactionsTab` function in UserPage.jsx was a module-level function using `theme` - fixed by adding `useTheme()` call inside it.
